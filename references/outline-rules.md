# 爆款大纲生成规则

本文件供 viral-outline-generator 内部引用，用于把"一条选题"展开成"一篇可写大纲"。

## 一、输入规格

接收：
- **选题**：从 topic-idea-generator 或人工输入的单条选题
- **平台**：公众号 / 小红书 / 抖音 / B站 / 知乎
- **受众**：年龄段 + 职业/身份 + 痛点
- **文章长度**：短（<800 字）/ 中（800-2000 字）/ 长（2000+ 字）

> 缺哪项用合理默认填充，不要反复追问。

## 二、开头钩子（必给 3 选 1）

按平台风格生成 3 种不同切入路径：

| 类型 | 公众号 | 小红书 | 抖音 |
|---|---|---|---|
| **场景化** | 真实场景还原 | 个人故事 + emoji | 镜头语言描述 |
| **反差钩** | A vs B 对比 | 震惊/意外语气 | 强冲突画面 |
| **数字钩** | 具体数字 + 收益 | 数字 + 圈层身份 | 时间数字 + 悬念 |

每种给完整 1 段（30-80 字），不是只给标题。

## 三、主体结构（按文章长度决定）

### 短文（<800 字） → 3 节结构

```
开头钩子（200 字）
↓
核心论点 1（150 字）
↓
核心论点 2（150 字）
↓
结尾 CTA（150 字）
```

### 中篇（800-2000 字） → 5 节结构

```
开头钩子（300 字）
↓
现象/痛点铺垫（300 字）
↓
核心拆解 / 步骤（500 字）
↓
案例 / 反例 / 数据（300 字）
↓
结尾 CTA（200 字）
```

### 长文（2000+ 字） → 7 节结构

```
开头钩子（400 字）
↓
背景 / 现象铺陈（400 字）
↓
核心拆解 1（400 字）
↓
核心拆解 2（400 字）
↓
案例 / 实战（500 字）
↓
总结升华 / 价值观（300 字）
↓
结尾 CTA（300 字）
```

## 四、关键素材点

每个主体节必须给出 1-2 个素材点，类型限以下 5 类：

- **截图类**：工具界面、对比表、聊天记录（要标注"需脱敏"）
- **数据类**：行业报告、统计数字（要标注"需核实来源"）
- **案例类**：真实人物/公司案例（要标注"需脱敏"）
- **金句类**：可单独引用的短句（带引号）
- **视觉类**：信息图、对比图、封面大字

不允许要求虚构数据。

## 五、结尾 CTA（按目的选 1）

| 目的 | 模板 |
|---|---|
| **评论引流** | 「你目前 X 是怎么做的？评论区聊聊」 |
| **下篇预告** | 「下篇我会拆解 X，评论区扣 1 我安排」 |
| **私域引流** | 「完整版/工具包在评论区置顶，拿去用」 |
| **行动召唤** | 「今天就试一下 X，回来告诉我效果」 |
| **价值观认同** | 「X 不是 Y，而是 Z（升华主张）」 |

## 六、输出大纲标准格式

```markdown
# [选题标题]

## 平台适配
- 公众号版：[标题]
- 小红书版：[标题 + emoji]
- 抖音版：[标题 + 镜头描述]

## 开头钩子（任选 1）
### A 场景化
[完整段落]

### B 反差钩
[完整段落]

### C 数字钩
[完整段落]

## 主体结构（[短/中/长]篇 → [3/5/7] 节）
### 第 1 节：[节标题]
- 字数：[N 字]
- 核心论点：[一句话]
- 素材点：[1-2 个]

### 第 2 节：...
...

## 关键素材清单
- [类型] [描述] （[脱敏/核实]）

## 结尾 CTA（[评论引流/下篇预告/...]）
[完整 CTA 段落]
```

## 七、Initialization 对话模板

```
你好，我是你的爆款大纲策划。
给我 1 条选题（或者直接说"从上一批选题里挑 #X"），加上目标平台和文章长度，我给你出完整大纲：
- 3 个开头钩子（场景/反差/数字）
- 主体结构（按长度自动给 3/5/7 节）
- 关键素材清单
- 1 个结尾 CTA

不告诉我长度也行，我按公众号中篇默认。
```
